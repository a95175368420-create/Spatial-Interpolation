# 監測資料庫 v3.4 直接匯入

上傳 `監測資料庫_v3.4_效能優化版.xlsx` 格式的工作簿，平台會辨識場址、樣品、點位、測項及原始結果，不需另外轉成CSV或提供欄位對應YAML。CLI及API的Excel上傳也共用這個匯入器。

## 下載與首次測試

- [已填合成範例](../examples/workbooks/monitoring_v34_demo.xlsx)：12個點位、72份樣品、288筆有效分析、12筆地下水位。土壤與地下水分開建點；所有數值均為合成測試資料。
- [空白範本](../examples/workbooks/monitoring_v34_blank.xlsx)：保留八張工作表、主檔、公式、選單與表格；主要資料表保留一列公式種子。

網站側欄的「v3.4範例、空白範本與座標設定」也提供下載。登入後選「上傳Excel或CSV」，上傳一個工作簿即可開始檢核、2D分布、趨勢、深度及3D實測展示，再從「成果匯出」下載ZIP。頁面會顯示辨識到的場址與樣品數。

## 每個新場址如何填寫

每個場址使用一份獨立工作簿，使用下列輸入欄；保留表頭、表格名稱及公式欄。可更改檔名，系統以內容辨識格式。

| 位置 | 填寫內容 |
| --- | --- |
| `00_使用說明!C5` | 本檔唯一場址名稱 |
| `03_點位主檔` A:L | 點位編號、介質、TWD97座標、井構造、高程、啟用及備註 |
| `01_樣品登錄` A:K | 唯一樣品編號、點位、日期、採樣深度、方法及備註 |
| `02_分析資料庫` A:D、H | 分析項目、原始值、單位、備註及「關聯鍵」；H必須對應01的樣品編號 |
| `04_測項與清單` DB_04 | 每個介質＋測項的唯一主檔、標準單位及啟用狀態；新測項可在表格末端新增 |

同點同日不同深度樣品須使用不同樣品編號。沒有資料的儲存格留空；重複、未知關聯或輸入欄出現公式會列入檢核結果，不默默合併。

## 深度、單位與高程

- 土壤使用01的F/G作為採樣區間；水樣使用E作為單點採樣深度，不由井篩長度推定樣品代表區間。
- 地下水01的F是距井口水位，不作為樣品深度。03備註若有 `wellhead_offset=0.5`（井口高於地面0.5m），可換為地表下水位；未指定時保留原值，列出基準未明訊息，不套疊成地表水位。
- TWD97預設121度分帶EPSG:3826，會列出預設採用訊息。119度分帶請於側欄選EPSG:3825，或在03備註明示 `crs=EPSG:3825`。設定檔的 `crs` 或側欄選擇可明確覆寫。
- 03「絕對高程」的地表基準若已確認，可於備註寫 `elevation_datum=ground`；否則保留來源高程，展示採相對深度。不可把井口高程直接標成地表高程。
- pH不取對數；ORP保留負值；EC識別μmho/cm、μS/cm及mS/cm等相容單位；DO濃度及飽和度分開；水樣與土樣TOC分開。平台只執行已支援的相容換算，未支援的換算列為異常，不盲目信任工作簿內的乘數。

v3.4沒有獨立的量測基準／溫度補償欄，可在01或02備註以分號分隔記錄以下明確欄位；02優先於01，其他備註原文保留。例如：

```text
合成資料；method=XRF; basis=dry
合成資料；temperature=25; temperature_compensated=yes; reference_temperature=25
合成資料；reference_electrode=Ag/AgCl; calibration=verified
```

`basis`：dry或wet（依實際報告填寫）；`method`：分析方法。未提供的資訊保持未知，不從數值或單位推測。土壤TOC缺質量基準會列為異常。

## 來源與公式

平台重新解析02的原始值，不採用G欄的公式快取。ND、上下界限及NA保留原文字與限定符，不代入零或半界限進行內插。這與範本Excel的G欄顯示策略不同；匯出的標準化表會保留來源工作表、實體列號及原始欄位。

範例及空白範本保留05的標準主檔，但清空07的版本選擇，避免對示範／新場址預選法規類別。平台不自動採用工作簿的法規門檻；需要時仍由明確設定的參數門檻、來源及適用條件管理。

八張v3.4工作表沒有岩性／地層區間表。匯入後不會憑空產生地質模型；需要地質柱狀或剖面時仍使用含 `geology` 的通用資料格式。

## 不同使用者及不同場址

每個瀏覽器工作階段各自上傳工作簿；使用者之間不共用上傳資料或計算結果。切換檔案後會清除前一份資料的篩選、已確認模型與下載結果。點位名稱可以在不同工作簿重複，場址及來源不會自動併入其他工作簿。

目前入口沿用測試網站密碼，尚無個別帳號、跨裝置資料保存或場址資料庫。離開前下載成果；登出會清除目前工作階段。

## 重建與驗證

```bash
.venv/bin/python scripts/build_v34_examples.py /path/to/監測資料庫_v3.4_效能優化版.xlsx
.venv/bin/spatial-monitor validate examples/workbooks/monitoring_v34_demo.xlsx
.venv/bin/python -m pytest -q tests/test_workbook_v34.py
.venv/bin/python tests/browser_workbook_v34.py --url http://127.0.0.1:8502
```

產生程式只讀取原範本，在目的資料夾輸出副本，依實際筆數調整表格並相對延伸公式。已用實際輸出xlsx驗證平台匯入，另驗證公式、計算欄metadata、名稱定義與資料驗證仍存在。未在原生Microsoft Excel操作新增列或實際重算；檔案已設定開啟時自動重算，此限制不影響平台重新解析原始輸入。
